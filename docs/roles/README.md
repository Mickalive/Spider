# SPIDER — ROLE ARCHITECTURE

This directory contains formal job descriptions for every active autonomous role in the current SPIDER organization. Each OpenCode agent must read its own role sheet before executing.

## Core scientific lanes

1. `GRAPH_RUNNER.md` — empirical Graph/memory/procedure engineering and falsification.
2. `PHYSICS_RUNNER.md` — falsifiable Web Physics experimentation.
3. `SCIENTIFIC_AUDITOR.md` — independent adversarial audit for Graph/Physics.
4. `LANE_DIRECTOR.md` — audited integration, program decisions, next mission and downstream product signal.
5. `META_DIRECTOR.md` — cross-lane shared-infrastructure reconciliation toward human-reviewed main.

## Competitive intelligence and mechanism R&D

6. `INTEL_SCOUT.md` — discovers and specifies externally evidenced mechanisms.
7. `INTEL_REPRODUCER.md` — clean-room reproduces one selected mechanism.
8. `INTEL_AUDITOR.md` — independently verifies reproduction and attribution.
9. `INTEL_RESEARCH_DIRECTOR.md` — integrates audited evidence and sets the next Intel mission.

## Product synthesis and beta creation

10. `PRODUCT_DIRECTOR.md` — combines audited Intel/Graph/Physics findings and decides when a benchmarkable beta is justified.
11. `BETA_ARCHITECT.md` — turns one authorized hypothesis into the minimal falsifiable product architecture and benchmark preregistration.
12. `BETA_BUILDER.md` — implements the beta faithfully and instrumentably.
13. `BETA_TESTER_AUDITOR.md` — independently tests whether the beta actually beats credible current-agent baselines.

## Core organizational rule

Evidence flows forward; incentives do not flow backward.

- Product desirability must never change a scientific verdict.
- External competitor claims must never reach Product/Graph/Physics as validated mechanisms before reproduction + audit.
- `REVISE` returns to the producing role; it never bypasses audit.
- A beta is successful only if it demonstrably improves a meaningful current-agent baseline on predeclared operational metrics.
- Negative results are retained as organizational knowledge.
- Public deployment/commercialization requires explicit human authorization.
