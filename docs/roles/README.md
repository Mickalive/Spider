# SPIDER — ROLE ARCHITECTURE

This directory contains formal job descriptions for the autonomous research/product organization.

## Competitive intelligence and mechanism R&D

1. `INTEL_SCOUT.md` — discovers and specifies externally evidenced mechanisms.
2. `INTEL_REPRODUCER.md` — clean-room reproduces one selected mechanism.
3. `INTEL_AUDITOR.md` — independently verifies the reproduction and attribution.
4. `INTEL_RESEARCH_DIRECTOR.md` — integrates audited evidence and sets the next research mission.

## Product synthesis and beta creation

5. `PRODUCT_DIRECTOR.md` — combines audited findings from Intel, Graph and Physics into product hypotheses and decides when a beta program is justified.
6. `BETA_ARCHITECT.md` — turns one authorized product hypothesis into a minimal falsifiable product architecture and benchmark plan.
7. `BETA_BUILDER.md` — implements the beta faithfully and instrumentably.
8. `BETA_TESTER_AUDITOR.md` — independently tests whether the beta actually beats current agentic baselines.

## Core organizational rule

Evidence flows forward; incentives do not flow backward.

- Product desirability must never change a scientific verdict.
- External competitor claims must never reach Product/Graph/Physics as validated mechanisms before reproduction + audit.
- A beta is successful only if it demonstrably improves a meaningful current-agent baseline on predeclared operational metrics.
- Negative results are retained as organizational knowledge.
