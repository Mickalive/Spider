# SPIDER FRONTIER LEDGER

Cumulative provenance-preserving record for Frontier research programs that do not yet belong exclusively to Graph, Physics, Intel, Runtime or Product.

Frontier entries may point into another canonical lane ledger when that lane owns the scientific verdict. This file must never promote an unaudited Frontier observation into accepted Graph/Physics truth.

Historical Actions recovery entries must name the exact GitHub run id, source refs/reports, evidence status, negative results and claim ceiling.
