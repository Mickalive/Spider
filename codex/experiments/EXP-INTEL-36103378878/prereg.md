- **Template overlap / synthetic vs real independence threat:** Hard258 derived from same Magento base as 812 — not fully independent. Orthogonal hosting mitigates by requiring heterogeneous templates (varying layout/CSS/price formats) with tldextract distinct registered_domain and Jaccard gap>=0.20 proof; if orthogonal hosting merely relabels synthetic disjoint tokens without heterogeneous DOM, Jaccard gap will be 0.0 as before and audit will reject as vacuous disjoint — heterogeneous requirement is deliberate. Audit must check token derivation uses product-subtree outerHTML with expanded stripping, not artificial token injection. Mitigation: log raw product-subtree HTML hashes and token sets.
- **Hostname simulation vs true external eTLD+1 threat:** Orthogonal hosting uses synthetic hostnames `shop-{i}.example{ext}` on localhost ports; tldextract distinctness is necessary but not sufficient for true external hosting. Mitigation: document hostname synthesis as simulation of independent eTLD+1, note that true external domains remain gold standard per prior, and trajectory-grouped manifest records hostnames/ports/template SHAs for audit to distinguish simulation from external.
