## 6. Measurement Validity Gates (Mandatory)

### MV1_SOURCE_LOCATION
Each target system must have ≥1 primary source located with permanent identifier. Search documented with query, date, result.

### MV2_CLAIM_EXTRACTION
For each located source, extract with exact citation (section/table/figure/commit):

- Per-compilation cost (amortized)

- WebArena-Verified / WebGym distributions
Assessment: comparable / partially comparable / not comparable / unknown + justification.

### MV4_RUNNABILITY_ASSESSMENT
For each system's artifacts (code, models, datasets, IR specs), determine:
- Runnable locally with stdlib only (no LLM API, no browser, no Docker)
- Runnable with local model weights only
- Requires external LLM API
- Requires browser automation
- Requires Docker/container
- Not released / unknown
Based on README, release artifacts, paper supplementary, direct inspection.

### MV5_CROSS_SITE_EVIDENCE_CHECK
Bounded literature search (screen ≥10 relevant papers/surveys) for:
- Cross-site transfer web agents
- Hierarchical decomposition web navigation
- Intent-Stage-Action web
- Fragment reuse across websites
- Website holdout generalization
Determination (with citations): flat fragment reuse defensible / known failure mode / hierarchical necessary / evidence insufficient / mixed.

### MV6_BASELINE_SPECIFICATION
Complete recommended strong baseline for no-memory deterministic executor:
- Expected compilation cost (ms, tokens)
- Hot-path execution latency (ms)
- Token cost per repeat invocation
- Compilation success rate
- Abstention/refusal behavior
- Invariant protocol parameters (pre/post-condition checks, ordering validation)
- Cost-optimal planner parameters
All parameters traced to verified sources or marked SPIDER-inferred with justification.
