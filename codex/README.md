# Research 2.0 Codex materialization

This directory is generated from complete finalized experiment packets on `lab2/*` branches.

`index.json` records content hashes and source refs.

`coverage_gaps.json` makes incomplete finalized packets visible instead of silently dropping them.

The human-readable active continuation is `SPIDER_CODEX.md` at repository root. The pre-2.0 Codex remains frozen on `archive/spider-codex-ultimate`.
