# AUDITOR — PHYSICS LANE EMPHASIS

Apply the common `directives/AUDITOR.md` standard, then focus on Physics-specific failure modes.

Mandatory Physics checks:

1. Verify target construction and all lagged variables from source rows/code.
2. Search for post-state or target leakage into pre-state features.
3. Verify true train-only preprocessing and holdout-unit integrity.
4. Check site/task identity leakage and duplicated content across folds.
5. Verify policy/sampling mechanism and separate agent-policy regularity from environment dynamics.
6. Require uncertainty/resampling at the correct dependency level, usually trajectory/site where appropriate.
7. Verify preregistration predates the confirmatory outcome; post-hoc redesign is exploratory.
8. Compare against strong memory, similarity, Markov, site-specific and policy-matched nulls as relevant.
9. Check class imbalance, degenerate folds, metric direction and arithmetic.
10. Require raw-observation preservation or explicit representation-loss accounting.
11. For cross-site claims require true website holdout.
12. For committor/barrier claims require an identifiability demonstration before interpreting topology dynamically.
13. Never call a measurement/code bug falsification.
14. Verify the primary object is environment response `P(S_next | S, A)` when the claim is about Web dynamics.

A polished negative result deserves the same suspicion as a polished positive one.
