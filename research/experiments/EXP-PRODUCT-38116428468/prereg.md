## 4. Hypothesis (H1-H7) and falsifier

- **H1 install identity:** installed `src/spider/kernel.py` == carrier (`718efa6a` / blob `b15ed848`) and != pre-install (`46929b3a` / blob `cfec9866`), and exposes `distill_parameterized`.
- **H2 confidence flow:** parameterized mechanisms distill to confidence **exactly** `0.9 >= 0.8` and can resolve `EXECUTABLE`; literal `distill()` candidates sit at exactly `0.5 < 0.8` and never resolve `EXECUTABLE` at the default threshold.
- **H3 positive inheritance on unseen identifiers (4-observation arm):** each of the 6 families, given 4 induction observations and the unseen held-out parameter values, resolves `EXECUTABLE` at exactly `0.9`, binds the requested unseen identifier, executes with fixture status `200`, and `verify()` true.
- **H3b minimum-induction arm:** the mandate requires `>= 3` induction observations; the identical round trip must also hold for every family when distilled from only 3 induction observations at exactly `0.9`.
- **H4 safe refusal:** all 24 declared negative cases (out-of-support, missing-parameter, wrong-intent) are refused (`!= EXECUTABLE`, null `bound_action`, non-empty reason); wrong-intent / no-applicable-mechanism returns exactly `ResolutionStatus.UNKNOWN`.
- **H5 attribution:** correct-binding advantage over the frozen retrieval comparator on unseen held-out identifiers is strictly positive.
- **H6 honesty:** `TrajectoryCounters` advance exactly `retrieval_calls=3, verification_calls=2, repair_attempts=1`, with `model_calls=model_tokens=browser_actions=http_requests=latency_ms=0`.
- **H7 abstention breadth:** with an empty `MechanismRegistry`, all six family intents and a never-seen intent resolve to exactly `ResolutionStatus.UNKNOWN` with null `bound_action` and a non-empty reason.

**Falsifier:** with `AD-IDENTITY-BINDING` passing, the certificate FALSIFIES if `CONFIDENCE-FLOW` fails (parameterized confidence not exactly `0.9` / `< 0.8`, or literal confidence set `!= {0.5}`, or no parameterized `EXECUTABLE`, or the literal path executes a held-out case) **or** `AD-POSITIVE-ROUNDTRIP` has 0/6 passes in either arm **or** `AD-NEGATIVE-ROUNDTRIP` fails (any unsafe case executed or wrong-intent not `UNKNOWN`). A partial positive (1-5/6 in either arm) with intact refusals and confidence flow is `MIXED`, not `SUPPORTS`. Failure of `AD-IDENTITY-BINDING`, of a measured prerequisite, of `P-FREEZE-INTEGRITY`, or of `NC-EMPTY-REGISTRY`/`NC-ZERO-CONTRAST` is `MEASUREMENT_INVALID`, never a scientific negative.

def sha256_bytes(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()


def git_blob_sha1(data: bytes) -> str:
    return hashlib.sha1(b"blob %d\0" % len(data) + data).hexdigest()


def write_json(path: Path, payload) -> str:
    path.parent.mkdir(parents=True, exist_ok=True)
    data = json.dumps(payload, indent=2, sort_keys=True).encode("utf-8")
    path.write_bytes(data)

def stable_context(family: dict) -> dict:
    return {"site": "fixture.invalid", "route": family["route"], "auth": "public"}


def params_for(mech, held_values: list) -> dict:
    supports = (mech.verification_rule or {}).get("parameter_supports", {})
    params: dict = {}
    used: set = set()
    for slot in mech.parameter_slots:
        matched = [v for v in held_values if v not in used and _support_accepts(supports.get(slot), v)]
        if len(matched) == 1:
            params[slot] = matched[0]
            used.add(matched[0])
        elif held_values:
            fallback = next(v for v in held_values if v not in used)
            params[slot] = fallback
            used.add(fallback)
    return params


def bound_identifier(family: dict, action: dict):
    try:
        return family["bound_identifier"](action)
    except Exception:
        return None


def positive_arm(n_induction: int, fam_obs: dict):
    """One positive arm at a fixed induction count. Returns per-family cases."""
    registry = MechanismRegistry(Path(tempfile.mkdtemp()) / f"pos{n_induction}.jsonl")
    kernel = SpiderKernel(registry, min_confidence=MIN_CONFIDENCE)
    cases = []
    for family in fx.FAMILIES:
        subset = fam_obs[family["family"]][:n_induction]
        m = kernel.distill_parameterized(subset)
        if m is not None:
            registry.upsert(m)
        ctx = stable_context(family)
        params = params_for(m, list(family["held_out"].values())) if m else {}
        res = kernel.resolve(family["intent"], ctx, params) if m else None
        bound = executed = None
        verified = False
        if res is not None and res.status == ResolutionStatus.EXECUTABLE and res.bound_action is not None:
            bound = bound_identifier(family, res.bound_action)
            executed = fx.fixture_execute(res.bound_action)
            verified = kernel.verify(m.mechanism_id, executed, params)
        expected = bound_identifier(family, family["build_action"](family["held_out"]))
        cases.append({
            "family": family["family"],
            "held_out": family["held_out"],
            "induction_observations": len(subset),
            "inferred_slots": list(m.parameter_slots) if m else [],
            "inferred_supports": (m.verification_rule or {}).get("parameter_supports") if m else None,
            "confidence": m.confidence if m else None,
            "resolution_status": res.status.value if res else None,
            "bound_identifier": bound,
            "expected_identifier": expected,
            "execution_status": (executed or {}).get("status"),
            "verify_true": verified,
            "pass": bool(
                m is not None and res is not None and res.status == ResolutionStatus.EXECUTABLE
                and m.confidence == PARAMETERIZED_CONFIDENCE and bound == expected
                and (executed or {}).get("status") == 200 and verified
            ),
        })
    n_pass = sum(1 for c in cases if c["pass"])
    return {
        "induction_count": n_induction,
        "n_cases": len(cases),
        "n_pass": n_pass,
        "pass_rate": n_pass / len(cases) if cases else 0.0,
        "in_support_executable_rate": sum(1 for c in cases if c["resolution_status"] == "EXECUTABLE") / len(cases) if cases else 0.0,
        "held_out_binding_correct_rate": sum(1 for c in cases if c["bound_identifier"] == c["expected_identifier"]) / len(cases) if cases else 0.0,
        "confidences": sorted({c["confidence"] for c in cases if c["confidence"] is not None}),
        "cases": cases,
    }

## 9. Decision rule and outcome mapping

- **FALSIFIES** iff `AD-IDENTITY-BINDING` passes AND (`CONFIDENCE-FLOW` fails OR `AD-POSITIVE-ROUNDTRIP` 0/6 in either arm OR `AD-NEGATIVE-ROUNDTRIP` fails).

## 11. Validity threats and self-attack

- **Near-determinism / information ceiling:** the positive control almost surely passes once the audited carrier is present. Disclosed. The discriminating content is the confidence-floor separation (0.9 parameterized vs 0.5 literal at the 0.8 gate), the typed refusals, the comparator contrast and the pinned identity, not the treatment's own success.
- **Comparator might be too weak:** addressed by using the frozen K=5 structural-nearest retrieval comparator on identical unseen inputs and by `NC-ZERO-CONTRAST`; a stronger retrieval baseline would only raise the bar, not invalidate a positive contrast.
- **Support-inference risk:** `distill_parameterized` infers per-slot support grammars from the induction set; if an unseen held-out value were out-of-support, H3 would fail a family. The frozen held-out values were checked in the probe to be in-support for all 6 families, and the fixture grammar accepts them.
- **Minimum-induction risk:** a family might support correctly at 4 observations but fail at the mandate minimum 3; the n=3 arm makes this observable as a partial (`MIXED`) rather than hiding it behind the n=4 arm.
- **Install identity could be satisfied by accident:** the check requires both the sha256 and the git blob, requires difference from the pre-install identity, and requires `distill_parameterized`; `b15ed848` is the audited carrier and no other content yields both.
- **Confounder: `models.py`/`registry.py` drift:** they are byte-identical to the carrier at DESIGN and are freeze artifacts; any drift breaks `P-FREEZE-INTEGRITY` -> `MEASUREMENT_INVALID`.
- **Promotion error:** `SUPPORTS` is necessary but not sufficient for promotion; the mandate requires an independent AUDIT PASS.
- **`B-SHIPPED-PRE-INSTALL` is identified by code identity, not executed separately:** the pre-install kernel lacks `distill_parameterized` and cannot be imported alongside the installed module under the same name; its blob/sha identity is read from `git HEAD:src/spider/kernel.py` inside the certificate.
- **Instrument robustness:** the accounting and freeze-integrity blocks were hardened during DESIGN so a genuinely broken treatment or tampered hash is reported as a failed check (not an exception); this was verified by the mutA/mutB/mutC/freeze-tampered probes.

## 12. Consequence of outcomes
