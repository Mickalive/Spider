- **Experiment ID**: EXP-FRONTIER-33528827909

- **Date**: 2026-09-01
- **Status**: DESIGN NOT YET FROZEN

## 2. Scientific Question

Do Web state transitions exhibit information flow structure (transfer entropy, mutual information) that reveals dynamical organization beyond what prediction accuracy metrics capture?

## 3. Motivation

Previous Physics lane work (WP-001, WP-002B, WP-003) focused on prediction accuracy metrics (dimension accuracy, exact match) to detect dynamical structure. These metrics answer "can we predict the next state?" but not "is there directed information flow between states and actions?"

Information-theoretic measures offer a complementary lens:
- **Transfer entropy** measures directed information flow from one variable to another
- **Conditional mutual information** measures shared information between variables given a third
- These measures are model-free and can detect nonlinear relationships

This experiment applies these measures to Web state transitions for the first time in SPIDER, testing whether they reveal structure invisible to prediction accuracy.

## 4. Hypotheses

### H1: Directed Information Flow
Transfer entropy from action to next-state (TE_action→next_state) exceeds zero under a Markov null.

### H2: State-Dependent Dynamics
Conditional mutual information between consecutive states given the action (I(S_{t+1}; S_t | A_t)) is positive.

### H3: Task Structure Correlation
Information-theoretic measures correlate with task structure (navigation vs form submission) in ways that prediction accuracy does not.

## 5. Data Sources

We will use existing transition data from pre2 experiments:
- **WP-002B dataset**: 300 trajectories, 901 transitions, true next-state information
- **Mind2Web dataset**: 176 valid tasks with action extraction
- **Synthetic control**: Generated deterministic finite automaton with known information flow

## 6. Measures

### 6.1 Transfer Entropy
TE(X→Y) = H(Y_{t+1} | Y_t) - H(Y_{t+1} | Y_t, X_t)

Where:
- X = action (discretized: click, fill, submit, navigate)
- Y = state (discretized: page type, URL structure, DOM features)

### 6.2 Conditional Mutual Information
I(S_{t+1}; S_t | A_t) = H(S_{t+1} | A_t) - H(S_{t+1} | S_t, A_t)

Where:
- S = state representation
- A = action

### 6.3 Estimation
- Use KSG estimator for continuous variables
- Use Miller-Madow correction for discrete variables
- Bias-corrected estimators required for small samples

## 7. Null Models

### 7.1 Markov Null
Next state depends only on current state, not action. Generated by:
- Permute action labels while keeping state sequence fixed

### 7.2 Shuffle Null
Transitions are independent of action. Generated by:
- Randomly permute action labels across all transitions

### 7.3 Frequency Null
Transitions follow marginal frequencies. Generated by:
- Sample next states from marginal distribution P(S_{t+1})

## 8. Statistical Tests

### 8.1 Primary Tests
- One-sided t-test: TE_action→next_state > 0
- One-sided t-test: I(S_{t+1}; S_t | A_t) > 0
- Correlation test: measure-task structure correlation

### 8.2 Multiple Comparison Correction
- Bonferroni correction for family-wise error rate
- False Discovery Rate (FDR) correction as sensitivity analysis

### 8.3 Sample Size Requirements
- Minimum 100 transitions per condition for reliable entropy estimation
- Power analysis: 80% power to detect medium effect size (d=0.5) at α=0.05

## 9. Controls

### 9.1 Positive Control
Synthetic deterministic finite automaton with:
- 5 states, 3 actions
- Known information flow structure
- TE should be > 0 by construction

### 9.2 Negative Control
Random walk on Web state graph with:
- No action-dependence
- Transitions proportional to node degree
- TE should be ≈ 0

## 10. Validity Threats

### 10.1 Sample Size Bias
Small samples can produce spurious entropy estimates. Mitigation: minimum sample size requirement, bias-corrected estimators.

### 10.2 Non-Stationarity
Web dynamics may change over time. Mitigation: stationarity check (measures stable across data splits).

### 10.3 Representation Loss
Discretization of states/actions may lose information. Mitigation: test multiple discretization granularities.

### 10.4 Multiple Comparisons
Testing multiple hypotheses increases false positive risk. Mitigation: Bonferroni/FDR correction.

## 11. Decision Rules

### 11.1 SURVIVES_CURRENT_TEST
If:
1. TE_action→next_state > 0 under Markov null (p<0.05 after correction)
2. I(S_{t+1}; S_t | A_t) > 0 under shuffle null (p<0.05 after correction)
3. Measures correlate with task structure (r>0.3, p<0.05)
4. All validity checks pass

### 11.2 FALSIFIED-IN-SETTING
If:
1. Any of the three hypotheses fails to reject null
2. OR measures show no task correlation
3. OR measures are dominated by sample size effects

### 11.3 MEASUREMENT_INVALID
If:
1. Sample size insufficient (<100 transitions per condition)
2. OR stationarity check fails
3. OR validity threats cannot be mitigated

## 12. Expected Outcomes

### 12.1 Positive Result (SURVIVES_CURRENT_TEST)
