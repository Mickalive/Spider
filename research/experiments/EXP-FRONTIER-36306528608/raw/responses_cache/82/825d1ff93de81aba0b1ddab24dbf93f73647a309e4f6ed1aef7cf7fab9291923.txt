            <p>AI coding assistants are changing how we build software.</p>
<p>But they still need context about your API.</p>
<h2>The problem</h2>
<p>When you ask Claude Code or Cursor to build something, you need to explain:</p>
<ul>
<li>Your API endpoints</li>
<li>Authentication headers</li>
<li>Request/response shapes</li>
<li>Your data model</li>
<li>Error handling patterns</li>
</ul>
<p>That&#39;s a lot of context to type out every time.</p>
<h2>Prompts that know your project</h2>
<p>We built LLM Prompts to solve this.</p>
<p>Each prompt template is pre-filled with your actual project data:</p>
<ul>
<li>Your API keys (manage + public)</li>
<li>Your collection names and schemas</li>
<li>The correct base URL</li>
<li>Auth flow examples with your keys</li>
<li>Error handling patterns</li>
</ul>
<p>Select your project, pick a prompt, copy it, paste it into your AI tool.</p>
<h2>Three categories</h2>
<h3>Build</h3>
<p>Full-stack React apps, authentication flows, admin dashboards, and simple CRUD starters. These prompts give the AI everything it needs to generate working code against your ReqRes backend.</p>

<h2>How it works</h2>
<p>Each prompt uses placeholders like <code>{{API_KEY}}</code> and <code>{{COLLECTIONS}}</code> that get replaced with your actual data when you copy.</p>
<p>For example, if you have a &quot;tasks&quot; collection with a schema, the prompt includes:</p>
<pre><code>### Collection: tasks
Endpoint: https://reqres.in/api/collections/tasks/records
Schema:
  - title: string
  - completed: boolean
</code></pre>
<p>The AI sees your real structure, not a generic example.</p>
<h2>The API key distinction</h2>
<p>We include both keys with clear guidance:</p>
<ul>
<li><strong>Manage key</strong> (<code>pro_*</code>) - Server-side only. CRUD operations, CI/CD.</li>
<li><strong>Public key</strong> (<code>pub_*</code>) - Browser-safe. Reads and magic link auth.</li>
</ul>
<p>The prompts explain when to use each, so the AI generates secure code by default.</p>
