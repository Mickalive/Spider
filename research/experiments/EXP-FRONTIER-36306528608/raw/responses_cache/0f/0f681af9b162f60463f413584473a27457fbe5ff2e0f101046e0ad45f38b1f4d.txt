  <section>
    <div class="sec-head reveal">
      <h2>Agents need a safe place to fail</h2>
      <span class="sec-tag">Why this exists</span>
    </div>
    <div class="why reveal">
      <div>
        <h3>Production bites back</h3>
        <p>An agent practicing retries against a real API is an incident waiting for a timestamp. Rate limits, real money, real customer data. None of it belongs in a training loop.</p>
      </div>
      <div>
        <h3>Mocks rot</h3>
        <p>Hand-rolled fixtures drift from reality the day you write them. ReqRes serves living, relational, versioned data (<code>users</code>, <code>orders</code>, <code>auth</code>), maintained so you never have to.</p>
      </div>
      <div>
        <h3>Flaky tests teach nothing</h3>
        <p>If the same request can return different bytes, your eval can't tell a model regression from network weather. Determinism makes agent failures reproducible, and therefore fixable.</p>
      </div>
    </div>
  </section>
