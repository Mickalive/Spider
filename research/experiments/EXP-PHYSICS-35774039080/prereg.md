All three are mathematically distinct: independent-noise falsification (0.004 bits) bakes in null for CMI but does not imply ACF decay is Markov exponential nor committor variance is zero. Director registry next_gate explicitly invites orthogonal programs (effect factorization, barriers, timescales, geometry, multiscale) — this chooses the two that are executable on already-collected trajectories.
- Uses validated Bayesian DM null framework that survived audit (BF calibration) rather than inventing new TV/KDE null; trajectory-grouped permutation (fixes item-level shuffle) and B-DOM-SIMILARITY (mandatory per mandate) are frozen.

### 4.3 Why existing TodoMVC/WebShop trajectories without Gate0

## 8. Measures

### 8.1 Primary timescale: bias-corrected ACF and Bayesian BF

For each (dataset, R in {R1,R2}):
```
ACF(k) = (1/(T-k)) sum_{t=1}^{T-k} [1_{S_t = S_{t+k}}]  averaged pooled weighted by trajectory length
normCorr(k) = weighted avg over s of (E[1_{S_t=s}1_{S_{t+k}=s}] - p_s^2)/(p_s(1-p_s))
delta_ACF(k) = ACF_obs(k) - mean(ACF_perm_grouped(k))  where perm_grouped = 1000 trajectory-grouped shuffles of S sequence preserving per-trajectory frequencies (seed 42)
tau via two-exp fit: ACF(k) ~ A*exp(-k/tau_fast) + B*exp(-k/tau_slow), tau_slow/tau_fast ratio, tau_int = sum_{k=0}^{k_max} ACF(k)
BF_10 = log P(data | M3)/P(data | M1) with Dirichlet-Multinomial K=12 states, alpha=1/K, N up to 1999, closed-form Gamma; per dataset fit on TRAIN grouped by trajectory_id (70/30 split)
```
Primary is delta_ACF(3) and BF nats>2.3; also report ACF(1), ACF(5), tau ratio, dwell distribution P(dwell=d) and heavy-tail exponent via MLE (power-law vs exponential via BF), null_mean/std, p_raw/p_bonf, Cohen d=delta_ACF/null_std, 95% CI via permutation percentiles.

### 8.2 Primary barrier: committor variance and bimodality

For each (dataset, R):
- Enumerate states x=(URL,DOM_hash) with >=3 revisits; branched_revisit_count = #x with >=10 revisits and >=2 distinct S_next values
- Define absorbing sets A/B as two most frequent terminal S values per dataset (if not defined, use divergent S_next distribution: hit_B = indicator S_next in top-2 frequent)
- q(x)=empirical fraction of revisits to x that hit B before A (or S_next in B) among revisits
- Var(q)=weighted variance across x with >=10 revisits (weights = revisit count)
- Dip test on q distribution: Hartigans dip statistic, p via 500 bootstrap resamples grouped by trajectory_id
- Null for Var(q): shuffle futures among revisits within same x (1000 perms grouped), mean/std, p_raw/p_bonf, Cohen d, 95% CI
- Report branched_revisit_count, divergent_future_rate, Var(q), dip p, feasible_barrier bool, avg_autocorr for completeness.

### 8.3 Auxiliary (per dataset per R)

NL, strata_count, singleton_rate, leakage_validOnly, link_share, unique_titles, title_entropy, H(S_next|C), dom_bytes coverage, null_mean/std, Cohen d, CI, B-DOM-SIMILARITY ACF_sim gap, action distribution, BF nats, tau_fast/slow, dwell exponent.

## 9. Null Models & Baselines (strong, all executed as frozen)

3. **B-SHUFFLE-GROUPED**: trajectory-grouped shuffle of S sequence preserving per-trajectory frequencies (1000 perms seed 42); yields null ACF and dwell null; valid null_std>0.01 required.
4. **B-DOM-SIMILARITY** (mandatory per mandate): kNN TF-IDF cosine / Jaccard over DOM visible_text and a11y text, k=5, fit on TRAIN only, predicting S_next via similarity without history; compute similarity-predicted ACF_sim(k) from similarity graph random walk; must be executed and gap ACF_obs - ACF_sim reported; timescale must beat similarity by >=0.05 to claim beyond-memory.

7. **B-SITE-LEAKAGE-DIAGNOSTIC**: PMI_leaky vs leakageFree gap for ACF delta; same estimator; valid inference uses leakageFree.

All baselines share identical grouping and seeds; preprocessing fit on TRAIN only.

## 10. Statistical Tests & Uncertainty (frozen, corrected per audit)

- **Permutation**: 1000 trajectory-grouped shuffles of S sequence (for ACF) and of futures among revisits within same x (for barrier), preserving per-trajectory frequencies and within-trajectory DOM sequences, seed 42 deterministic, grouped by trajectory_id (shuffle across trajectories but within same dataset). Null = delta_ACF_perm and Var(q)_perm distributions. Resampling unit = trajectory_id; no Gaussian jitter.
- **p-value**: p_raw = (1 + #{perm >= observed})/1001 one-sided. Bonferroni primary: p_bonf = min(1, p_raw * Q * n_prongs * n_reps) where Q up to 6, n_prongs=2 (T/B), n_reps=2 (R1/R2) => max divisor 24, alpha 0.05/24=0.00208 rounded to frozen 0.005 conservatism. Report raw and Bonferroni. Positive controls: raw p<0.005 single test reachable at N=1000 floor 0.001.
- **BF**: log BF computed exactly via Gamma functions, no resampling; BF nats >2.3 corresponds to BF>10 strong evidence.
- **Effect size**: Cohen d = delta_ACF / null_std (null_std>0.01 required); 95% CI via grouped permutation percentiles (2.5th/97.5th), NOT Gaussian.
- **Dip p**: Hartigans dip via 500 bootstrap grouped resamples; p<0.05.
- **Seed determinism**: PYTHONHASHSEED=0, numpy seed 42, sklearn random_state 42; builtin hash() with PYTHONHASHSEED=0 deterministic but still use SHA256 for state hashing; do NOT use hash() for grouping.
