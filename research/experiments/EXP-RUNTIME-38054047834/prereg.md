## 4. Substrate declaration ADB-v2

ADB-v2 is a credential-free, locally-served, deterministic multi-page REST substrate.

- **Transport**: Python 3.12 standard library `http.server.ThreadingHTTPServer` on `127.0.0.1` with an
  OS-chosen ephemeral port (the port is not part of the frozen declaration identity). No browser, no external
  network, no credentials, no cookies, no model calls.
- **Families**: `F1`, `F2`.
- **Test sessions**: 3 per family; each session has 4 tasks, one at each novelty level `n in {0.0, 0.25, 0.5, 0.75}`,
  in that order. 3 x 2 x 4 = 24 test tasks per arm.
- **Training demos**: 2 sessions per family x 2 fully-resolved demonstration tasks (novelty 0.0) = 8 demos, the
  only induction source for the mechanism.
- **Session graph**: root page (1 request) links the hub; the hub (1) lists a 6-node boot chain (6 requests). For
  a single-task episode the b6 response is the task spec directly (so a stateless episode reaches its spec in
  `root+hub+boot(5)+spec_at_b6 = 8` discovery requests). For a 4-task session the b6 response links a task-list
  (1) and then the first task spec (1), so the session discovery cost is `10`.
- **Hidden parameters**: a task at level `n` has `h(n) = 8n` hidden parameters, i.e. `h in {0, 2, 4, 6}`. Each
  parameter renders two indistinguishable candidate slots (one real, one decoy). A stateless arm must probe both
  (2h requests); a schema-aware mechanism resolves the h real slots (h requests). The decoy slots are the
  discovery-cost driver; they return a decoy marker rather than the required value.
- **Task enumeration** (deterministic; `n` printed with the `%g` rule so `0.0 -> 0`): for each family
  `f in {F1,F2}`, each test session `s in {1,2,3}`, each level `n`:
  task id `f-S{s}-n{n}` with `novelty=n`, `h=8n`, `order_in_session` = level index. Train demos:
  `f-T{t}-{d}` for `t in {1,2}`, `d in {1,2}`, `novelty=0.0`, `h=0`.
- **Budgets**: per-task integer HTTP-request budget `B={0.0:14, 0.25:15, 0.5:17, 0.75:19}`, applied identically
  to every arm. Budgets grow with novelty (deliberately lenient toward comparators).
- **Seed**: `20261010`. All topology, ordering and slot values are a pure function of the frozen declaration and
  this seed.
- **Route-token leak rule**: no rendered task spec, slot page, hub or boot page may contain an absolute URL or
  any of the literals `/s/`, `{sid}`, `/boot/`, `/hub`, or a session id; only the arm's own navigational relative
  links are permitted. Checked in DESIGN (probe 3) and re-checked at EXECUTE (gate I7).

|---|---|---|---|---|---|
| `B-COLD-RE-DERIVE` | S | S | F | F | 4, 1, -1, -3 |

Mean per-attempt comparator-minus-treatment gaps (the monotonicity signal):

| gap | n=0.0 | n=0.25 | n=0.5 | n=0.75 |
|---|---|---|---|---|
| cold - treatment | 5.5 | 7.5 | 9.5 | 11.5 |
| retrieval - treatment | 8.5 | 10.5 | 12.5 | 14.5 |

Both rows are strictly increasing (`h+5.5` and `h+8.5`); each adjacent increment is exactly `+2`. Static route
traces (probe 3) have lengths exactly equal to these costs:

- cold: `[root, hub, boot x5, spec, slot x2h, commit, verify]` = `2h+10`
- retrieval: `[root, hub, boot x5, spec, idx x3, slot x2h, commit, verify]` = `2h+13`
- treatment session: `[root, hub, boot x6, task_list, spec] + sum_over_levels([slot x h, commit, verify])` = 30
- PC: `[slot x h, commit, verify]` = `h+2`
- OOS refusal: `[root, hub]` then refuse (2 requests; no commit, no verify)

Trace signatures are pairwise distinguishable: retrieval = cold signature plus `idx`; the treatment session
contains `task_list` while single-task episodes do not; PC lacks the session walk; OOS refuses without `commit`.
The only within-session shared route set is `{slot, commit, verify}` between treatment-others and PC, which is
expected because both are schema-aware; the treatment's extra session walk (task 1) and its refusal behavior keep
the episode/transaction level distinguishability.

## 7. Controls

Stable control identifiers (downstream stages must reuse these exact names):

- **`B-COLD-RE-DERIVE`** — strong stateless comparator; per-task isolation enforced by the runner (no cross-task
  memory). Expected high-novelty success `0/12`; failure of the isolation (success at high novelty) is F1.
- **`B-RETRIEVAL-SHAPED`** — strong retrieval comparator; 3 leave-instance-out index probes per task, all charged.
  Expected high-novelty success `0/12`; retrieval reaching ceiling is F1.
- **`T-AMORT-REUSE`** — the treatment: session-amortized discovery plus an induced hidden-parameter schema;
  resolves in-support tasks, refuses out-of-family sessions. Expected 12/12 at every level.
- **`PC-FOREKNOWN-SCHEMA`** — positive control (solvability ceiling): given the schema and slot URIs out of band,
  must reach 12/12 at high novelty. Excluded from the comparator minus-treatment margin. Failure -> `I1`.
- **`PC-EXACT-SESSION-REPLAY`** — replay the 6 treatment test sessions and require exact per-route counter
  equality with the original runs. Failure -> `I5`.
- **`NC-OOS-TYPE`** — 5 out-of-family sessions; the treatment must refuse all 5 (false accepts 0). Failure -> `I2`.
- **`NC-BUDGET-TRUNCATION`** — 6 episodes at high novelty with the runner-imposed budget reduced by 6; the runner
  must stop at budget with zero overrun and record a partial/failed state. Failure -> `I3`.

Expected-vs-observed for every control is recorded in `result.json.controls` keyed by these identifiers, each with
a pass/fail/unknown and an exact evidence reference.

## 8. Decision rule

Integrity gates (all must hold before any scientific verdict; any failure -> MEASUREMENT_INVALID):

- `I1` `PC-FOREKNOWN-SCHEMA` 12/12. `I2` `NC-OOS-TYPE` false accepts 0/5. `I3` `NC-BUDGET-TRUNCATION` zero
  overrun on 6 episodes. `I4` `M-COUNTER-RECONCILE` mismatches 0. `I5` `PC-EXACT-SESSION-REPLAY` exact.
  `I6` render-declaration digest `== D1` and predicted-certificate digest `== D2`. `I7` route-token leak absent.
  `I8` determinism (repeated episode byte-identical counters).

Propositions (measured only if the integrity set holds):

- `P1` cold high-novelty point<0.95 AND Wilson lo<0.90. `P2` retrieval high-novelty point<0.95 AND lo<0.90.
- `P3` treatment 12/12 at high and low novelty. `P4` both comparator gaps strictly increasing and pooled 6/6
  adjacent increments > 0. `P5` minimum high-novelty mean gap >= 3. `P6` exact certificate agreement.

Verdict mapping (precedence total; SUPPORTS/FALSIFIES/MIXED partition the integrity set):

1. any integrity failure -> `MEASUREMENT_INVALID` (repair, do not reinterpret);
2. `P1..P6` all hold -> `SUPPORTS`;
3. `NOT (P1 AND P2)` -> `FALSIFIES` (a comparator reaches the high-novelty ceiling);
4. `P1 AND P2 AND NOT (P6 OR P4 OR P5)` -> `MIXED` (ceiling separation holds, cost-model/trend agreement does not);
5. substrate bring-up / transport failure prevents the matrix -> `INCONCLUSIVE`.

Each branch is reachable; see `spec.json#decision_rule.reachability_certificate` and probe 3's branch walk.

## 10. EXECUTE procedure and abort gates

1. Bring up the site (stdlib, `127.0.0.1:ephemeral`); assert the route canary.
2. Render the declaration and predicted certificate; assert canonical digests equal `D1`/`D2` (`I6`). Also scan
   for route-token leaks (`I7`).
3. **Low-novelty liveness block (post-freeze abort gate):** run `T-AMORT-REUSE` on the 12 low-novelty tasks; if
   any fails, abort to MEASUREMENT_INVALID (treatment not live).
4. Run the 72 test episodes (3 arms x 24) with a fixed, seeded arm/session order.
5. Run `PC-FOREKNOWN-SCHEMA` (12 high-novelty), `NC-OOS-TYPE` (5), `NC-BUDGET-TRUNCATION` (6), and
   `PC-EXACT-SESSION-REPLAY` (6 sessions). Interleave a determinism re-run (`I8`).
6. Reconcile counters (`I4`), compute the success matrix, gaps, monotonicity and the decision rule, and emit
   `result.json`, `report.md`, `provenance.json` plus the artifacts in Section 15.

Any infrastructure failure is recorded with the exact error and mapped to MEASUREMENT_INVALID or INCONCLUSIVE; it
is never encoded as a scientific negative.

## 11. Validity threats, representation loss, and non-claims

- The substrate is **synthetic by design**; it certifies instrument dynamic range and honesty under declared
  non-omniscient policies, **not** transfer to the open Web or to a real LLM agent. Readiness condition (3)
  remains open.
- `SUPPORTS` is largely the frozen declaration taking effect; the genuinely falsifiable pathways are
  implementation divergence, route/index leakage, counter dishonesty, budget-truncation behavior, out-of-family
  false acceptance, and any arm behavior differing from the arithmetic.
- The monotonicity test on 4 levels has modest standalone power (`p=1/24` per arm); it is a secondary signal. The
  primary discrimination rests on the exact high-novelty ceiling separation (`P1`/`P2`/`P3`) and the ledger
  agreement (`P6`).
- The treatment is a deterministic declared mechanism, not a Product carrier; no Product promotion is implied.
- Cost is measured in HTTP requests, not wall-clock or bytes; representation of "work" is deliberately narrow.
- `do_not_assume`: that these numbers are Web-realistic; that the bank is difficult for a capable LLM agent; that
  the treatment's induced store generalizes beyond in-family sessions.

## 12. Freeze eligibility

Exactly the six required checks; every one is a claim the independent DESIGN REVIEWER must attack.

1. **`decision_rule_reachability` — PASS.** Pure arithmetic certificate computed in DESIGN with no outcomes; the
   accept region is non-empty at `n=12` (`k=0` -> point 0.0, lo 0.0; `k=12` -> point 1.0, lo 0.7575); every
   verdict branch has a concrete reachable scenario; precedence is total and branch-safe.
2. **`measurement_prerequisites` — PASS.** Python 3.12 stdlib import probe (python 3.12.15) and a localhost
   `ThreadingHTTPServer` canary both succeeded in DESIGN; the entire bank is a deterministic function of the
   frozen declaration and seed, so no external site, dataset, credential, browser or model endpoint is required.
3. **`baseline_identifiability` — PASS.** Comparator per-task costs exceed the budgets at high novelty while the
   treatment fits every level, so success profiles are provably distinct; every cost dimension each comparator
   pays is charged (stateless session re-pay + decoys; retrieval index probes included); trace signatures are
   distinguishable; the retrieval index is leave-instance-out.
4. **`control_sensitivity` — PASS.** Positive, null, truncation, replay, leak, counter, digest and determinism
   controls can each fire under the same implementation that scores the experiment, and each failure maps to a
   distinct integrity gate; none is tautological.
5. **`treatment_liveness` — PASS.** The treatment is a declared deterministic mechanism, not an external Product
   carrier; its session cost fits every level, the low-novelty liveness block is the post-freeze abort gate, and
   its disjoint counter signature demonstrates a genuinely different procedure.
6. **`freeze_artifacts_bound` — NOT_APPLICABLE.** No pre-existing mutable local file/code/task bank/dataset/fixture
   is consumed; `freeze_artifacts` is empty by contract. The interpretation surface is declared in the frozen
   packet and additionally pinned by `D1`/`D2`; EXECUTE-produced code is fingerprinted in `result.json.artifacts`
   and recomputed by AUDIT.

## 13. Consequences

- **Positive (`SUPPORTS`)**: a hash-pinned, non-degenerate asymmetric-discovery bank with certified comparator
  headroom and honest counters is available to downstream lanes, removing readiness condition (2); later treatment
  advantages are no longer at risk of being unreachable-margin artifacts. No product promotion.
- **Negative (`FALSIFIES`)**: session-amortized asymmetric discovery does not create headroom on the
  credential-free localhost class; the program must change the discovery asymmetry (e.g. third-party/adversarial
  populations) or scope the benchmark to a real-agent-capable substrate once readiness condition (3) is met; the
  four-arm benchmark is not funded on this class.
- **`MIXED`**: headroom retained but the declared cost model/trend must be corrected before reuse.
- **`MEASUREMENT_INVALID`**: instrument repaired before any downstream spend; not a scientific negative.
- **`INCONCLUSIVE`**: smallest unblocking action recorded; not a scientific negative.

## 18. DESIGN adversarial satisfiability pass (self-attack)

Performed before finalizing, in addition to the four probes; each attack and its disposition:

1. **Empty/unreachable decision branches.** SUPPORTS, FALSIFIES, MIXED, MEASUREMENT_INVALID and INCONCLUSIVE each
   have a concrete trigger (Section 8; `spec.json#decision_rule.reachability_certificate`). The partition is total.
   Nonblocking note: FALSIFIES requires a comparator at `k=12/12` high-novelty (point 1.0); intermediate comparator
   success `1..11/12` satisfies `P1`/`P2` but breaks `P6` and therefore maps to MIXED, which is the intended
   detector for "headroom exists but the declaration did not take effect".
2. **Arithmetic impossibility.** Found and repaired in the inherited draft (Section 3): retrieval `{1,1,0,0}` at
   `B={12,15,16,18}` is impossible with cost `2h+13`. The repaired `B={14,15,17,19}` gives every predicted cell at
   least one request of margin/deficit and strictly monotone budgets.
3. **Ceiling/floor baselines.** Comparators are neither at ceiling nor at floor: at high novelty cold/retrieval are
   predicted `0/12`, and at low novelty cold is `2/2` while retrieval is `1/2`, so both a level effect and an
   arm effect are observable. The treatment is not at floor (12/12). The positive control is a solvability ceiling,
   not a comparator.
4. **Treatment/comparator identity.** No arm runs a shared model or shared policy; treatment and comparators differ
   mechanically (session-amortized discovery + induced store + OOS refusal vs per-task discovery + decoy probing;
   retrieval adds leave-instance-out index probes). Static route signatures are distinguishable (Section 5). The
   only shared per-task signature (`slot, commit, verify` between treatment-others and the schema-aware PC) is
   expected and is separated at the session/transaction level and by the OOS-refusal behavior.
5. **Insensitive controls.** Every control can fail and each failure maps to a distinct gate (`I1`..`I8`); none is
   tautological (Section 7, Section 12 check 4).
6. **Missing prerequisites.** Standard library and localhost transport are verified available now (probes 1, 4, 5);
   the task bank is a deterministic function of the frozen declaration and seed, so nothing external is required.
7. **Unbound mutable artifacts.** None exist; `freeze_artifacts` is empty with `freeze_artifacts_bound`
   NOT_APPLICABLE, and the interpretation surface is pinned by `D1`/`D2` (Section 12 check 6).

Nonblocking limitations disclosed for downstream: the 4-level monotonicity test is secondary (`p=1/24` per arm);
the substrate is synthetic; `I6` is byte-exact and therefore depends on EXECUTE loading the frozen JSON verbatim;
cost is measured in HTTP requests only.
